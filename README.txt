ظلّ النظام — مشروع موقع محلي
================================

الملفات:
- index.html : صفحات الموقع.
- style.css  : التصميم الأسود والأخضر المتجاوب.
- app.js     : التفاعلات والأدوات.

التشغيل:
1. فك ضغط ZIP.
2. افتح index.html بمتصفح الهاتف أو ارفع المجلد إلى استضافة مواقع ثابتة مجانية.
3. بعض المتصفحات لا تتيح SHA-256 عند فتح الملف مباشرة file://؛ استخدم استضافة HTTPS أو خادمًا محليًا لهذه الميزة.

الأدوات:
- فاحص نصوص/أكواد بقواعد بسيطة (لا يشغّل الكود ولا يضمن سلامته).
- منسّق نصوص.
- مولّد كلمات مرور.
- بصمة SHA-256 عبر Web Crypto.
- ملاحظات محفوظة في localStorage على نفس المتصفح.

الخصوصية:
- لا توجد API ولا حسابات ولا اتصالات خادمية مقصودة.
- Google Fonts قد يحاول تحميل الخطوط من الإنترنت؛ إن أردت نسخة بلا أي اتصال خارجي، احذف سطر @import من style.css وسيستخدم المتصفح الخطوط البديلة.
- لا تضع أسرارًا أو كلمات مرور داخل الملاحظات.
- هذا إصدار أولي قابل للتطوير لاحقًا بمساعدة AI.
